# Hardware decision plan
Existing: WiiM Mini + Lenovo Tiny server/kiosk; reuse existing portable monitors for prototype before buying.
Candidate compact: ASUS ZenScreen OLED MQ16FC 16-inch 1920x1200, listing around $280; verify mounting, HDMI/USB-C, DDC/CI, night minimum brightness, standby wake.
Candidate known thin: ASUS ZenScreen OLED MQ16AH 15.6-inch 1920x1080, approx 8.95mm, mini HDMI and USB-C DP Alt, typical 15W, tripod socket, no standard VESA. Excellent black; glossy and burn-in concerns.
Candidate premium: UPERFECT 16-inch 3K OLED 2880x1800 120Hz, listing around $420; verify physical dimensions, warranty, DDC/CI, power and mount.
Candidate large art: Samsung The Frame 32-inch, listing around $600; matte art presentation and built-in ambient sensor in Art Mode. Caveat: external HDMI kiosk may not inherit Art Mode sensor brightness or auto art behavior; test exact model year.
Alternative mobile: LG StanbyME 2 27-inch, around $800-1000; portable but bulky and expensive.
Score each for: black level, minimum luminance, glare, size at viewing distance, depth including mount/cables, power, mounting, VESA, DDC/CI, HDMI-CEC, auto-on/wake, burn-in warranty, price.
Recommended approach: start on existing monitor; select 16-inch OLED if close viewing; 32-inch framed screen if wall viewing. Use Lenovo Tiny HDMI kiosk with local gateway. Validate kiosk wake, cable concealment and physical brightness before purchasing.
